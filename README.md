## Grupo 8: Algoritmos de cadenas

- **Búsqueda de patrones:** Definición del problema de encontrar una secuencia de caracteres dentro de un texto y explicación de sus elementos principales.

- **Búsqueda ingenua:** Explicación del método de búsqueda directa de un patrón, comparando el patrón con las diferentes posiciones posibles del texto.

- **KMP (Knuth-Morris-Pratt):** Explicación del algoritmo KMP y de cómo utiliza información previamente obtenida del patrón para evitar comparaciones innecesarias.

- **Rabin-Karp:** Explicación del algoritmo Rabin-Karp y del uso de funciones hash para localizar posibles coincidencias de un patrón dentro de un texto.

- **Prefijos y sufijos:** Explicación de estos conceptos y de su importancia en algoritmos de búsqueda de patrones, especialmente en KMP.

- **Función hash:** Cálculo y actualización del hash utilizado por Rabin-Karp.

- **Comparación de algoritmos:** Comparación entre la búsqueda ingenua, KMP y Rabin-Karp considerando sus estrategias y características.

- **Selección del algoritmo:** Explicación de los criterios que permiten determinar qué algoritmo resulta más conveniente según las características del problema.
