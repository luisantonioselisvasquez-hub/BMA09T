## Grupo 6: Caminos mínimos

- **Problema del camino mínimo:** Definición del problema de encontrar el camino de menor costo entre dos vértices o entre todos los pares de vértices de un grafo.

- **Dijkstra:** Explicación del algoritmo para encontrar caminos mínimos desde un vértice origen en grafos con pesos no negativos.

- **Bellman-Ford:** Explicación del algoritmo para encontrar caminos mínimos en grafos que pueden contener aristas con pesos negativos y detección de ciclos negativos.

- **Floyd-Warshall:** Explicación del algoritmo para encontrar los caminos mínimos entre todos los pares de vértices mediante un enfoque basado en programación dinámica.

- **Comparación de algoritmos:** Comparación entre Dijkstra, Bellman-Ford y Floyd-Warshall considerando el tipo de problema que resuelven y sus principales características.

- **Relajación de aristas:** Operación utilizada para actualizar y mejorar las distancias conocidas hacia los vértices.

- **Selección del algoritmo:** Explicación de qué algoritmo resulta adecuado según las características del grafo y del problema planteado.
